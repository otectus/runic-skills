## Historical

Everything in [`history/`](history/) is a point-in-time record kept for provenance. Each carries a
dated banner saying which version it describes and what has since changed. **Do not act on one
without checking the code**: they describe versions between 1.3.7 and 1.6.1.

## Asset source of truth

Which paths are authored, which are generated, and which are archived — so nobody has to guess
again whether a directory of PNGs is source art or a stale export.

| Path | Status |
| --- | --- |
| `src/main/resources/assets/runicskills/textures/skill/**` | **Shipped.** Perk and passive icons. Generated by [`../tools/icongen/gen.py`](../tools/icongen) from `specs.tsv`; that spec is the source, the PNGs are output |
| `src/main/resources/assets/runicskills/textures/power/**` | **Shipped, generated.** Power icons, produced by [`../tools/icongen/powers.py`](../tools/icongen/powers.py) directly from `RegistryPowers`. Regenerate rather than editing; `PowerIconCoverageTest` fails the build if one is missing, orphaned, or a duplicate |
| `src/main/resources/assets/runicskills/textures/particle/**` | **Shipped, generated.** The runic glyph sheet used by proc VFX |
| `src/main/resources/assets/runicskills/textures/gui/**`, `item/**` | **Shipped, hand-authored.** No generator |
| `tools/icongen/**` | **Source.** Generator scripts, glyph libraries and the `specs.tsv` inputs. Not shipped in the jar |
| `icons/` (repository root) | **Unresolved.** 399 PNGs that share no content hash with the shipped textures. Provenance is not established, so they are neither deleted nor treated as source; see below |
| `tab_menu_buttons.png` (repository root) | **Unresolved.** A third-party asset with an unclear licence, referenced by nothing |

The two unresolved entries are deliberately left in place. Deleting art whose provenance nobody has
established is not reversible in the way that leaving it is, and the licensing question on
`tab_menu_buttons.png` wants an answer rather than a `git rm`. Neither ships in the jar — the jar
takes only `src/main/resources` — so their cost is repository size and confusion, not distribution.
